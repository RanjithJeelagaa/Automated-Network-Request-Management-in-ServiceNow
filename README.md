# Automated Network Request Management System

## 📌 Project Overview

The **Automated Network Request Management System** is a ServiceNow application developed to simplify and automate the process of requesting network devices and services through the Service Catalog.

Instead of manually handling requests, users can submit requests through the Service Portal, where approvals, task creation, and notifications are automatically managed using ServiceNow workflows.

---

## 🎯 Objectives

- Automate network device and service requests.
- Reduce manual effort and approval delays.
- Improve request tracking and transparency.
- Provide a centralized platform for managing network requests.

## ⚙️ Workflow

1. User logs into the Service Portal.
2. Opens the Network Request catalog item.
3. Selects the required device or network service.
4. Fills in the required information.
5. Submits the request.
6. Request is sent for approval.
7. After approval:
   - Tasks are automatically created.
   - Assigned to the Network Support team.
8. Network team completes the task.
9. Request is closed after successful completion.
